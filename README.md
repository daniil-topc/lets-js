# let's JS

Справочник по синтаксису JavaScript для тех, кто только начинает. Шесть глав ведут от первой переменной до запроса на сервер.

## Какую проблему решает

Новичку трудно учить синтаксис по документации: она написана для тех, кто уже программирует, и редко показывает, зачем конструкция нужна на практике. Здесь каждая тема разобрана в три шага:

1. Объяснение простыми словами, через бытовое сравнение. Переменная описана как подписанная коробка, функция как рецепт, промис как номерок в кафе.
2. Реальный кейс: где это встречается на настоящих сайтах. Для `setTimeout()` это уведомление, которое исчезает само, и поиск, который ждёт, пока человек допечатает.
3. Живой пример: код из кейса работает прямо на странице, его можно потрогать.

## Главы

| № | Глава | Что внутри |
|---|-------|------------|
| 01 | Основы | `let`, `const`, типы данных, операторы, шаблонные строки |
| 02 | Условия и циклы | `if / else`, тернарный оператор, `switch`, `for`, `while`, `for...of` |
| 03 | Функции | объявление, параметры, `return`, стрелочные функции, область видимости |
| 04 | Массивы и объекты | `map`, `filter`, `reduce`, деструктуризация, spread, JSON |
| 05 | DOM и события | `querySelector`, `classList`, `addEventListener`, создание элементов |
| 06 | Асинхронность | `setTimeout`, `setInterval`, промисы, `async / await`, `fetch` |

## Справочник по React

В папке `public/react` лежит второй справочник, let's React. Он устроен так же и рассчитан на тех, кто уже прошёл главы по JavaScript. Между справочниками переключает кнопка JS / React в шапке.

| № | Глава | Что внутри |
|---|-------|------------|
| 01 | Компоненты и JSX | компонент, JSX, правила JSX |
| 02 | Пропсы | передача данных, значения по умолчанию, `children`, функции в пропсах |
| 03 | Состояние и события | `onClick`, `useState`, обновление состояния, поля ввода |
| 04 | Условия и списки | `&&`, тернарный оператор, `map`, `key` |
| 05 | Эффекты | `useEffect`, зависимости, очистка, `useRef` |
| 06 | Данные и свои хуки | загрузка данных, свой хук, контекст |

Сам React на сайт не подключён. Живые примеры в этих главах написаны на обычном JavaScript и повторяют поведение компонентов из кода рядом.

## Стек

Фронтенд написан на чистом HTML, CSS и JavaScript, без фреймворков, сборщиков и библиотек. Подсветку кода, оглавление и переключатель темы делает собственный скрипт.

Бэкенд работает на Node.js (версия 18 или новее) и Express 5. Три пакета отвечают за защиту и скорость:

- `helmet` ставит заголовки безопасности, включая Content Security Policy;
- `express-rate-limit` ограничивает число запросов с одного IP;
- `compression` сжимает ответы.

Шрифты Inter и JetBrains Mono и иконки [Lucide](https://lucide.dev) лежат в проекте, поэтому сайт не обращается к внешним ресурсам.

Переменные окружения:

| Переменная | Зачем |
|------------|-------|
| `PORT` | порт сервера, по умолчанию 3000 |
| `NODE_ENV=production` | включает HSTS и кэширование статики на сутки |
| `TRUST_PROXY=1` | нужен за nginx или прокси хостинга, иначе лимит запросов считает всех посетителей одним IP |

Сайт многостраничный: каждая глава лежит в отдельном HTML-файле, и сервер отдаёт его как есть. Шаблонизатора и сборки нет.

### Как сервер обрабатывает запрос

Запрос проходит через цепочку обработчиков в `server.js`:

1. `helmet` добавляет заголовки безопасности. CSP разрешает скрипты, стили и шрифты только со своего домена и запрещает показывать сайт в чужом `iframe`.
2. Фильтр методов пропускает только `GET` и `HEAD`, остальные получают ответ 405.
3. Общий лимит: 300 запросов в минуту с одного IP.
4. `GET /api/tip` возвращает случайный совет в JSON. У этого адреса свой лимит, 30 запросов в минуту.
5. `express.static` отдаёт файлы из `public`. Скрытые файлы вроде `.env` наружу не выходят.
6. Всё остальное получает страницу 404. Обработчик ошибок не показывает клиенту стек и внутренние детали.

### Как работают живые примеры

В разметке пример выглядит как блок с атрибутом `data-demo`:

```html
<div class="demo" data-demo="toast">...</div>
```

В `demos.js` лежит объект, где каждому имени соответствует функция. При загрузке страницы скрипт находит все блоки `data-demo` и запускает функцию с тем же именем. Чтобы добавить пример, нужно написать разметку на странице и одну функцию в этом объекте.

Пример в главе про `fetch` обращается к `/api/tip`, поэтому работает только при запущенном сервере.

### Тема

Выбранная тема хранится в `localStorage` под ключом `theme`. Скрипт `theme-init.js` подключён в `<head>` и ставит атрибут `data-theme` на `<html>` до загрузки стилей, поэтому страница не мигает при открытии. Если пользователь тему ещё не выбирал, берётся системная.
