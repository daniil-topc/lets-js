Пропсы

Пропсы превращают один компонент в сотню разных. Через них в компонент приходят тексты, числа и даже функции.

Как передать пропсы

Компонент без настроек всегда показывает одно и то же. Чтобы одна кнопка могла быть и синей, и серой, ей нужны входные данные. В React они называются пропсами. Работают они как аргументы функции: ты передаёшь значения снаружи, компонент использует их внутри.

Снаружи пропсы выглядят как атрибуты тега. Внутрь они приходят одним объектом.

function Greeting(props) {
  return <h2>Привет, {props.name}!</h2>;
}

function App() {
  return (
    <>
      <Greeting name="Аня" />
      <Greeting name="Марк" />
    </>
  );
}

Строки передаются в кавычках. Всё остальное идёт в фигурных скобках: числа, булевы значения, массивы, объекты и функции.

<ProductCard
  title="Наушники"
  price={7900}
  inStock={true}
  tags={['звук', 'bt']}
/>

Деструктуризация и значения по умолчанию

Писать props. перед каждым именем утомительно. Обычно объект разбирают на переменные прямо в скобках функции. Там же можно задать значение на случай, если пропс не передали.

function Button({ label, variant = 'primary' }) {
  return <button className={`btn btn--${variant}`}>{label}</button>;
}

<Button label="Купить" />                    // variant будет 'primary'
<Button label="Отмена" variant="ghost" />

Ниже один и тот же компонент Button. Меняй его пропсы и смотри, что он показывает.

Живой пример

Пропсы внутри компонента менять нельзя. Они принадлежат тому, кто их передал. Если значение должно меняться, ему место в состоянии, о нём рассказывает следующая глава.

children

У каждого компонента есть особый пропс children. В него попадает всё, что ты написал между открывающим и закрывающим тегом. Так делают обёртки: рамку, модальное окно, карточку, внутри которой может лежать что угодно.

function Card({ title, children }) {
  return (
    <section className="card">
      <h3>{title}</h3>
      {children}
    </section>
  );
}

<Card title="Доставка">
  <p>Привезём завтра с 10 до 18.</p>
  <button>Изменить время</button>
</Card>

Функции в пропсах

Данные в React идут сверху вниз, от родителя к ребёнку. Чтобы ребёнок мог сообщить что-то наверх, родитель передаёт ему функцию. Ребёнок вызывает её, когда происходит событие.

function AddToCart({ onAdd }) {
  return <button onClick={onAdd}>В корзину</button>;
}

function Product() {
  function handleAdd() {
    console.log('Товар добавлен');
  }

  return <AddToCart onAdd={handleAdd} />;
}
Реальный кейс

Витрина из одного компонента

Сервер присылает массив товаров. Компонент карточки один, а пропсы у каждой карточки свои. Через пропсы приходит и функция, которая кладёт товар в корзину, поэтому карточке не нужно знать, как корзина устроена.

function ProductCard({ title, price, onAdd }) {
  return (
    <article className="card">
      <h3>{title}</h3>
      <p>{price.toLocaleString('ru-RU')} ₽</p>
      <button onClick={() => onAdd(title)}>В корзину</button>
    </article>
  );
}

function Catalog() {
  const addToCart = (title) => console.log(`В корзине: ${title}`);

  return (
    <>
      <ProductCard title="Наушники" price={7900} onAdd={addToCart} />
      <ProductCard title="Колонка" price={12500} onAdd={addToCart} />
    </>
  );
}
