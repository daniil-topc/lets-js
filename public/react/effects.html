Эффекты

Таймеры, заголовок вкладки и подписки находятся за пределами React. Эффекты связывают компонент с этим внешним миром.

useEffect

Компонент должен только считать разметку из пропсов и состояния. Но иногда нужно выйти за пределы React: запустить таймер, поменять заголовок вкладки, подписаться на событие окна, сходить на сервер. Такие действия называют эффектами, и для них есть хук useEffect.

Он принимает функцию и запускает её после того, как компонент появился на экране.

import { useEffect, useState } from 'react';

function Cart() {
  const [count, setCount] = useState(0);

  useEffect(() => {
    document.title = `В корзине: ${count}`;
  }, [count]);

  return <button onClick={() => setCount(count + 1)}>Добавить</button>;
}

Массив зависимостей

Второй аргумент useEffect говорит, когда запускать эффект заново. Это массив значений, за которыми эффект следит. React сравнивает их с прошлым разом и запускает эффект, только если что-то изменилось.

ЗаписьКогда запускается
useEffect(fn, [])Один раз, когда компонент появился
useEffect(fn, [count])При появлении и после каждого изменения count
useEffect(fn)После каждой перерисовки, нужно редко

Перечисляй в массиве все пропсы и состояния, которые эффект читает. Если что-то пропустить, эффект будет работать со старым значением, и такую ошибку трудно заметить.

Очистка

Таймер, запущенный в эффекте, продолжит тикать, даже когда компонент уже исчез со страницы. Чтобы этого не случилось, верни из эффекта функцию. React вызовет её, когда компонент убирают или перед следующим запуском эффекта. Правило простое: что эффект включил, то очистка выключает.

useEffect(() => {
  const timerId = setInterval(() => {
    console.log('тик');
  }, 1000);

  return () => clearInterval(timerId);   // очистка
}, []);
Реальный кейс

Секундомер на тренировке

Пока секундомер включён, число растёт каждую секунду. Эффект следит за флагом running: когда он становится истинным, запускается интервал. Когда флаг выключают или компонент убирают, очистка останавливает интервал.

function Stopwatch() {
  const [seconds, setSeconds] = useState(0);
  const [running, setRunning] = useState(false);

  useEffect(() => {
    if (!running) return;

    const timerId = setInterval(() => {
      setSeconds((prev) => prev + 1);
    }, 1000);

    return () => clearInterval(timerId);
  }, [running]);

  return (
    <>
      <p>{seconds} с</p>
      <button onClick={() => setRunning(!running)}>
        {running ? 'Пауза' : 'Старт'}
      </button>
    </>
  );
}

useRef

Иногда нужен прямой доступ к элементу страницы: поставить курсор в поле, прокрутить к блоку, измерить ширину. Хук useRef создаёт коробку, в которую React положит ссылку на элемент. Сам элемент лежит в свойстве current.

Изменение этой коробки не вызывает перерисовку, в этом её отличие от состояния.

import { useRef } from 'react';

function Search() {
  const inputRef = useRef(null);

  return (
    <>
      <input ref={inputRef} placeholder="Поиск" />
      <button onClick={() => inputRef.current.focus()}>
        Найти
      </button>
    </>
  );
}
