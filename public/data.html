Массивы и объекты

Данные редко приходят по одному. В магазине сотни товаров, и у каждого есть название, цена, фото. Для списков в JavaScript есть массивы, для описания одной вещи есть объекты.

Массивы

Массив хранит значения по порядку, как список покупок. У каждого элемента есть номер, и тут первая ловушка для новичка: счёт идёт с нуля. Первый элемент имеет номер 0, второй номер 1.

const fruits = ['яблоко', 'банан', 'киви'];

fruits[0];        // 'яблоко' — первый элемент
fruits[2];        // 'киви'
fruits.length;    // 3 — сколько элементов

fruits.push('манго');     // добавить в конец
fruits.pop();             // убрать последний
fruits.includes('банан'); // true — есть ли такой
fruits.indexOf('киви');   // 2 — на каком месте
fruits.join(', ');        // 'яблоко, банан, киви'

map, filter, reduce

Со списками обычно делают три вещи: переделывают каждый элемент, отбирают нужные или считают итог. Для этого у массива есть методы map, filter и reduce. Каждому ты передаёшь функцию, и он применяет её ко всем элементам по очереди.

Исходный массив при этом остаётся как был. Методы возвращают новый результат.

const prices = [100, 250, 400];

// map — превратить каждый элемент во что-то другое
const withTax = prices.map((price) => price * 1.2);
// [120, 300, 480]

// filter — оставить только подходящие
const cheap = prices.filter((price) => price < 300);
// [100, 250]

// reduce — свернуть весь массив в одно значение
const total = prices.reduce((sum, price) => sum + price, 0);
// 750

// find — найти первый подходящий
const first = prices.find((price) => price > 200);
// 250

Фильтр товаров по цене

Ползунок «цена до» есть в любом каталоге. Когда ты его двигаешь, filter отбирает товары дешевле выбранной цены, а reduce складывает их стоимость.

const products = [
  { title: 'Чехол для телефона', price: 890 },
  { title: 'Беспроводная мышь', price: 1990 },
  { title: 'Наушники', price: 7900 },
];

function getAffordable(maxPrice) {
  return products.filter((product) => product.price <= maxPrice);
}

const list = getAffordable(2000); // чехол и мышь
const total = list.reduce((sum, product) => sum + product.price, 0); // 2880

    Объекты

    Объект описывает одну вещь со всеми её свойствами. Похоже на анкету: слева название поля, справа ответ. Имя: Аня, возраст: 21. Название поля программисты называют ключом, а ответ значением. Чтобы прочитать значение, напиши имя объекта, точку и ключ.

    const user = {
  name: 'Аня',
  age: 21,
  isAdmin: false,
  greet() {
    return `Привет, я ${this.name}`;
  },
};

user.name;        // 'Аня'
user.age = 22;    // изменить свойство
user.city = 'Минск'; // добавить новое
user.greet();     // 'Привет, я Аня'

Object.keys(user); // ['name', 'age', 'isAdmin', 'greet', 'city']

    Заполни анкету и посмотри, как выглядит объект.

    Деструктуризация и spread

    Писать user.name, user.age, user.city по десять раз утомительно. Деструктуризация достаёт нужные значения из объекта или массива в отдельные переменные за одну строку.

    Три точки (...) называются spread. Они «высыпают» содержимое объекта или массива в новый, и так удобно делать копию с небольшими изменениями.

    const user = { name: 'Аня', age: 21, city: 'Минск' };

// Деструктуризация — вместо user.name, user.age
const { name, age } = user;

const [first, second] = ['яблоко', 'банан'];
// first → 'яблоко', second → 'банан'

// Spread (...) — копия с изменениями
const older = { ...user, age: 22 };
const more = [...['a', 'b'], 'c']; // ['a', 'b', 'c']

    JSON

    Объект живёт в памяти программы, и отправить его на сервер или сохранить в браузере напрямую нельзя. Сначала его превращают в текст. Формат этого текста называется JSON, и выглядит он почти как обычный объект JavaScript. JSON.stringify делает из объекта строку, JSON.parse превращает строку обратно в объект.

    const settings = { theme: 'dark', fontSize: 16 };

// Объект → строка
const text = JSON.stringify(settings);
// '{"theme":"dark","fontSize":16}'

// Строка → объект
const data = JSON.parse(text);
data.theme; // 'dark'

    Поменяй настройки и посмотри, какая строка получится.

    Запомнить тему сайта

    Кнопка темы в шапке этого сайта запоминает твой выбор в localStorage. Это хранилище внутри браузера, и данные в нём остаются после перезагрузки страницы. Переключи тему, обнови страницу и убедись сам.

    const button = document.querySelector('#themeToggle');

button.addEventListener('click', () => {
  const current = document.documentElement.dataset.theme;
  const next = current === 'dark' ? 'light' : 'dark';

  document.documentElement.dataset.theme = next;
  localStorage.setItem('theme', next); // сохранили
});

// При загрузке страницы — достаём сохранённое
const saved = localStorage.getItem('theme'); // 'dark' или null
