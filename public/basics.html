Основы

Здесь три темы: переменные, типы данных и операторы. Они встречаются в каждой программе, поэтому с них и начинаем.

Переменные: let и const

Представь коробку, на которой написано имя. Внутрь можно положить что угодно: число, текст, список покупок. В JavaScript такая коробка называется переменной. Ты создаёшь её, даёшь имя и кладёшь значение.

Создать переменную можно словом let или const. Разница одна: в коробку let можно положить что-то другое, а коробка const заклеена навсегда.

let score = 0;        // значение можно менять
score = 10;           // всё в порядке

const PI = 3.14;      // значение менять нельзя
PI = 3;               // Ошибка: Assignment to constant variable

constНетПочти всегда, начинай с него
letДаСчётчики, очки в игре, всё, что меняется
varДаСтарый способ, встретишь его в чужом коде

Пиши const, пока можешь. Если позже значение понадобится изменить, поменяешь слово на let. Так труднее случайно испортить значение, которое меняться не должно.

Типы данных

Значения бывают разных типов. Число 5 и текст '5' выглядят похоже, но для JavaScript это разные вещи: числа он складывает, а тексты склеивает. Поэтому 5 + 5 даёт 10, а '5' + '5' даёт '55'.

Вот типы, с которыми ты будешь работать каждый день:

const title = 'Наушники';      // string — строка
const price = 7900;            // number — число
const inStock = true;          // boolean — да / нет
let discount;                  // undefined — значение не задано
const promo = null;            // null — «пусто» специально
const tags = ['звук', 'bt'];   // array — список
const user = { name: 'Аня' };  // object — набор свойств

typeof title;    // 'string'
typeof price;    // 'number'
typeof inStock;  // 'boolean'

Если не знаешь, что лежит в переменной, спроси у typeof. Он ответит названием типа. Напиши в поле ниже число, слово или true.

Операторы

Операторы тебе знакомы со школы: плюс, минус, больше, меньше. В коде они работают так же, только умножение пишется звёздочкой, а деление косой чертой.

// Арифметика
10 + 5;   // 15
10 - 5;   // 5
10 * 5;   // 50
10 / 4;   // 2.5
10 % 3;   // 1 — остаток от деления

// Сравнение
5 > 3;        // true
5 === 5;      // true — строгое равенство
5 === '5';    // false — число и строка
5 !== 3;      // true — «не равно»

// Логика
true && false;  // false — И: оба должны быть true
true || false;  // true  — ИЛИ: хватит одного
!true;          // false — НЕ: переворачивает

Оператор % новичков путает. Он возвращает остаток от деления. Десять конфет делим на троих: каждому по три, одна лишняя. Эта лишняя и есть 10 % 3.

Живой пример

Два знака равно (==) сравнивают небрежно: JavaScript сам переделывает типы и считает, что 0 == '' верно. Три знака (===) сравнивают честно, пользуйся ими.

Строки и шаблоны

Строка хранит текст. Её пишут в кавычках, и подойдут любые: одинарные, двойные или обратные (клавиша с буквой Ё). Обратные удобнее остальных, потому что внутрь можно вставить переменную через ${}, и JavaScript подставит её значение.

const name = 'Аня';
const age = 21;

// Старый способ — склеивание через плюс
const a = 'Меня зовут ' + name + ', мне ' + age;

// Шаблонная строка — то же самое, но читается проще
const b = `Меня зовут ${name}, мне ${age}`;

// Полезные свойства и методы
name.length;          // 3 — длина
name.toUpperCase();   // 'АНЯ'
'  привет  '.trim();  // 'привет' — убирает пробелы по краям
'JS это просто'.includes('просто'); // true
Реальный кейс

Приветствие по имени

Строку «Привет, Аня!» в личном кабинете собирает шаблонная строка: берёт то, что ввёл пользователь, и вставляет в готовую фразу. Метод trim() заодно убирает пробелы, которые человек случайно поставил в начале или в конце.

const input = document.querySelector('#name');
const output = document.querySelector('#greeting');

input.addEventListener('input', () => {
  const name = input.value.trim();
  output.textContent = `Привет, ${name}! В твоём имени ${name.length} букв.`;
});
