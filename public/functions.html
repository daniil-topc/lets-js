Глава 03

Функции

Допустим, один и тот же кусок кода нужен тебе в пяти местах. Копировать его пять раз плохая идея: найдёшь ошибку и будешь править все пять копий. Функция решает эту проблему. Ты пишешь код один раз, даёшь ему имя и потом вызываешь по имени.

Объявление и вызов

Функция похожа на рецепт. Записать рецепт в тетрадь и приготовить по нему блюдо можно в разные дни. С функцией так же: сначала её объявляют (записывают рецепт), потом вызывают (готовят). Вызов выглядит как имя и круглые скобки после него. Без скобок ничего не произойдёт.

// Объявление
function sayHello() {
  console.log('Привет!');
}

// Вызов
sayHello(); // Привет!
sayHello(); // Привет! — можно сколько угодно раз

Каждое нажатие кнопки вызывает функцию заново.

Параметры и return

Рецепту нужны продукты, а функции нужны данные. Их передают в круглых скобках, и называются они параметрами. Результат функция отдаёт словом return. После return функция сразу заканчивается, и значение попадает туда, где её вызвали.

Параметру можно задать значение по умолчанию. Оно пригодится, если при вызове данные не передали.

function sum(a, b) {
  return a + b;
}

const total = sum(2, 3); // 5

// Значение по умолчанию — если аргумент не передали
function greet(name = 'гость') {
  return `Привет, ${name}!`;
}

greet('Аня'); // 'Привет, Аня!'
greet();      // 'Привет, гость!'

console.log() только печатает значение в консоль, использовать его дальше нельзя. Если результат нужен в другом месте программы, верни его через return.

Реальный кейс

Цена со скидкой в интернет-магазине

Скидку в магазине считают в карточке товара, в корзине и в чеке. Формула при этом одна, и лежит она в одной функции. Когда маркетологи поменяют правила, программист исправит одно место.

function getFinalPrice(price, discount = 0) {
  return Math.round(price - (price * discount) / 100);
}

getFinalPrice(7900, 15); // 6715
getFinalPrice(7900);     // 7900 — скидки нет

Стрелочные функции

У функции есть короткая запись со стрелкой =>. Работает она так же, только писать меньше. Стрелочные функции чаще всего передают внутрь других функций, например в обработчик клика или в методы массивов. В следующих главах ты увидишь их постоянно.

// Обычная функция
function double(n) {
  return n * 2;
}

// То же самое стрелкой
const double2 = (n) => {
  return n * 2;
};

// Если тело — одно выражение, скобки и return не нужны
const double3 = (n) => n * 2;

double3(4); // 8

Функция double из примера работает прямо здесь. Поменяй число.

Область видимости

Переменная живёт внутри тех фигурных скобок, где её создали. Снаружи её не видно. Это как комнаты в квартире: то, что лежит в твоей комнате, из коридора не достать, зато всё, что стоит в коридоре, доступно из любой комнаты.

const site = "let's JS"; // видна везде

function showInfo() {
  const secret = 42;     // видна только внутри функции
  console.log(site);     // работает
  console.log(secret);   // работает
}

showInfo();
console.log(secret); // Ошибка: secret is not defined

Благодаря этому функции не мешают друг другу. В двух разных функциях могут быть переменные с одинаковым именем, и они не перепутаются.
