Глава 05

DOM и события

До этой главы код только считал и выводил результат в консоль. Теперь он будет менять саму страницу. Браузер представляет каждый тег HTML в виде объекта, и вместе эти объекты называются DOM. Через них JavaScript находит элементы, меняет их и удаляет.

Поиск элементов

Чтобы изменить элемент, его нужно сначала найти. Команда document.querySelector ищет на странице первый элемент, который подходит под описание. Описание пишется так же, как селектор в CSS: 'h1' для тега, '.btn' для класса, '#signup' для id.

Если нужны все подходящие элементы, бери querySelectorAll. Он вернёт список.

// Первый подходящий элемент
const title = document.querySelector('h1');
const button = document.querySelector('.btn');
const form = document.querySelector('#signup');

// Все подходящие — получится список
const cards = document.querySelectorAll('.card');

cards.forEach((card) => {
  console.log(card);
});

Когда элемент не найден, querySelector возвращает null. Ошибка Cannot read properties of null почти всегда означает опечатку в селекторе.

Изменение элементов

У найденного элемента можно поменять текст, классы, атрибуты и стили. Текст лежит в свойстве textContent, классами управляет classList.

const title = document.querySelector('h1');

title.textContent = 'Новый заголовок';   // текст

title.classList.add('is-active');        // добавить класс
title.classList.remove('is-active');     // убрать
title.classList.toggle('is-active');     // переключить

title.style.color = 'tomato';            // стиль напрямую

const link = document.querySelector('a');
link.setAttribute('href', '/about');     // атрибут

Блок ниже найден через querySelector. Кнопки меняют его текст и класс.

События

Клик, нажатие клавиши, отправка формы: всё, что делает пользователь, браузер называет событиями. Команда addEventListener просит браузер следить за элементом. Ты говоришь ей, какое событие ждать и какую функцию запустить, когда оно случится.

В функцию браузер передаёт объект события с подробностями. Через event.target можно узнать, на каком именно элементе всё произошло.

const button = document.querySelector('button');

button.addEventListener('click', () => {
  console.log('По кнопке кликнули!');
});

// Объект события — подробности о том, что произошло
const input = document.querySelector('input');

input.addEventListener('input', (event) => {
  console.log(event.target.value); // текущий текст в поле
});

Реальный кейс

Кнопка «Нравится»

Лайк под постом устроен просто. Клик увеличивает число в переменной, новое число записывается в кнопку, а класс is-liked перекрашивает её.

const button = document.querySelector('.like-btn');
const count = document.querySelector('.like-count');
let likes = 0;

button.addEventListener('click', () => {
  likes++;
  count.textContent = likes;
  button.classList.add('is-liked');
});

Создание элементов

Новый элемент появляется на странице в три шага. Сначала ты создаёшь его, потом наполняешь текстом, потом вставляешь в нужное место. Пока третий шаг не сделан, элемент существует только в памяти и на странице его не видно.

const list = document.querySelector('ul');

const item = document.createElement('li'); // 1. создать
item.textContent = 'Купить молоко';        // 2. наполнить
list.appendChild(item);                    // 3. вставить

item.remove(); // удалить со страницы

Текст, который ввёл пользователь, вставляй только через textContent. Если использовать innerHTML, злоумышленник сможет написать в поле вредный код, и он выполнится у других посетителей. Такая атака называется XSS.

Реальный кейс

Список дел

Форма добавляет задачу в список, а клик по задаче её удаляет. Обрати внимание на event.preventDefault(). Без этой строки браузер после отправки формы перезагрузит страницу, и список пропадёт.

const form = document.querySelector('form');
const input = document.querySelector('input');
const list = document.querySelector('ul');

form.addEventListener('submit', (event) => {
  event.preventDefault(); // не перезагружать страницу

  const text = input.value.trim();
  if (!text) return; // пустую задачу не добавляем

  const item = document.createElement('li');
  item.textContent = text;
  list.appendChild(item);
  input.value = '';
});

// Клик по задаче — удалить её
list.addEventListener('click', (event) => {
  if (event.target.tagName === 'LI') {
    event.target.remove();
  }
});
