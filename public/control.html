Условия и циклы

Программа часто должна выбирать: пустить пользователя или нет, показать скидку или обычную цену. За выбор отвечают условия. А когда одно действие нужно повторить много раз, помогают циклы.

if / else

Ты пользуешься условиями каждый день: если на улице дождь, беру зонт, иначе иду так. В коде то же самое. В круглых скобках стоит вопрос, на который можно ответить «да» или «нет». Если ответ «да», выполняется код в первых фигурных скобках. Если «нет», JavaScript переходит к else.

const age = 17;

if (age >= 18) {
  console.log('Доступ открыт');
} else if (age >= 16) {
  console.log('Доступ с согласия родителей');
} else {
  console.log('Доступ закрыт');
}
// Выведет: Доступ с согласия родителей
Реальный кейс

Проверка пароля при регистрации

Форма регистрации подсказывает, что не так с паролем, прямо во время ввода. Внутри у неё цепочка проверок: сначала длина, потом наличие цифры. Сработает первая проверка, которая найдёт проблему.

function checkPassword(value) {
  if (value.length < 8) {
    return 'Слишком короткий';
  } else if (!/\d/.test(value)) {
    return 'Добавь хотя бы одну цифру';
  } else {
    return 'Отличный пароль!';
  }
}

Тернарный оператор

Иногда условие нужно только для того, чтобы выбрать одно из двух значений. Для этого есть короткая запись в одну строку: условие ? если да : если нет. Читай её как вопрос: «Товар есть? Тогда пиши „В наличии“, иначе „Нет в наличии“».

const count = 3;

// Длинно
let label;
if (count > 0) {
  label = 'В наличии';
} else {
  label = 'Нет в наличии';
}

// Коротко — то же самое
const status = count > 0 ? 'В наличии' : 'Нет в наличии';

Поменяй количество товара на складе и посмотри, какую надпись выберет тернарный оператор.

Живой пример

Тернарный оператор внутри другого тернарного читать очень трудно. Если вариантов больше двух, бери if или switch.

switch

Бывает, что одно значение нужно сравнить с целым списком вариантов. Статус заказа, например, может быть «новый», «в пути» или «доставлен», и для каждого нужен свой текст. Длинная цепочка else if тут превращается в кашу, а switch раскладывает варианты по полочкам.

const status = 'shipped';
let text;

switch (status) {
  case 'new':
    text = 'Заказ принят';
    break;
  case 'shipped':
    text = 'Заказ в пути';
    break;
  case 'done':
    text = 'Заказ доставлен';
    break;
  default:
    text = 'Статус неизвестен';
}
// text → 'Заказ в пути'

Живой пример

После каждого варианта ставь break. Без него JavaScript не остановится и выполнит код следующего варианта тоже.

Цикл for

Цикл повторяет код столько раз, сколько скажешь. В скобках у for три части через точку с запятой. Первая создаёт счётчик, вторая проверяет, продолжать ли, третья меняет счётчик после каждого круга.

Запись i++ означает «увеличь i на единицу».

//   начало     условие   шаг
for (let i = 1; i <= 5; i++) {
  console.log(`Шаг ${i}`);
}
// Шаг 1, Шаг 2, Шаг 3, Шаг 4, Шаг 5
Реальный кейс

Рейтинг звёздами

Оценка товара в интернет-магазине рисуется циклом. Он идёт от 1 до 5 и на каждом шаге спрашивает: этот номер меньше оценки или равен ей? Если да, ставит закрашенную звезду, иначе пустую.

function renderStars(rating) {
  let stars = '';
  for (let i = 1; i <= 5; i++) {
    stars += i <= rating ? '★' : '☆';
  }
  return stars;
}

renderStars(3); // '★★★☆☆'

Живой пример

while и for...of

Цикл while подходит, когда число повторов заранее неизвестно. Он крутится, пока условие в скобках верно. Так работают попытки ввода пин-кода: пока попытки остались, спрашиваем ещё раз.

А for...of перебирает массив: берёт элементы по одному, от первого до последнего, и для каждого выполняет код.

// while — пока есть попытки
let attempts = 3;
while (attempts > 0) {
  console.log(`Осталось попыток: ${attempts}`);
  attempts--;
}

// for...of — каждый элемент по очереди
const fruits = ['яблоко', 'банан', 'киви'];
for (const fruit of fruits) {
  console.log(fruit);
}

Если условие в while никогда не станет ложным, цикл не остановится и вкладка зависнет. Проверь, что внутри цикла меняется то, что стоит в условии.
